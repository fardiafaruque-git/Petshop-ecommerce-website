

A simple pet shop website built with **HTML, CSS, JavaScript, PHP** and a server-side storage (file/DB).  
Deployed live: **[http://petshopproject.infinityfreeapp.com/Project/?i=1]**  

---

## 🔥 Overview

This is an e-commerce style website for pet lovers. Users can browse pets and products, add items to cart, apply for pet-sitting, submit adoption requests, and leave comments/reviews.

---

## ✨ Key Features

- 🔐 **Simple Auth** — Login/register for users.
- 🛒 **Add to Cart** — Browse products and add/remove items to a shopping cart.  
- 💬 **Comments / Reviews** — Users can leave comments or reviews on pet profiles or product pages.  
- 🐶 **Pet Sitter Application System** — A form for users to apply as a petsitter; admin can review applications.  
- 🏠 **Pet Adoption** — Users can submit adoption requests for listed pets.  
- 🧴 **Pet Products** — Product listing with basic details (price, description, stock).  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Storage:** MySQL
